<%:Command examples%>

<%:All commands run in a shell on the router (SSH or the ttyd web terminal). The settings page above provides the defaults; command line options always win.%>
<%:Basic%> 
dss
<%:Prompt is [shell]>. Type exit to quit. Multi-line answers stream in place.%>
dss "用一句话解释什么是 SLIC 接口"
printf "1+1=?\n中国的首都是哪里？\n" | dss
<%:Attachments and web search%> 
dss --file /root/AR9341.PDF "这份文档里 SLIC 的 DMA 描述符怎么定义？"
<%:Several --file options are allowed; the files are uploaded once per session.%>
dss --search "今天有什么重要的科技新闻？"
dss --pace 8 "问题"
<%:Seconds between API calls. Raise it when DeepSeek answers "too frequent".%>
<%:Code mode and self-dialogue%> 
dss --code "用 C 写一个读取 /proc/meminfo 打印 MemAvailable 的完整程序"
<%:Answers without a code block are re-asked automatically. Cut-off code is continued from the break point.%>
dss --code --file /root/AR9341.PDF --file /root/SI3217XB.PDF \
    --duet --rounds 5 --minutes 30 --pace 8 \
    "使用 ar9341 通过 slic 接口对接 si3217x 实现 voip 全代码"
<%:rounds 0 = unlimited, Ctrl-C stops. The banner shows CODE MODE when it is active.%>
<%:Slash commands inside the dss prompt%> 
!list            列出这条回答里保存的代码文件
!cat 1           查看第 1 个文件
!run 1           执行（.sh / .py / .c，C 会先 gcc 编译）
!run 1 send      执行并把输出/编译错误发回给模型继续修
!out 1           把上次执行输出发回对话
!upload /root/AR9341.PDF    上传并附加到后续问题
!files                      列出已附加文件
!refile                     下次提问重新发送附件
!detach                     清空附件
!search on|off     联网搜索开关
!help              帮助
exit               退出
